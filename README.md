# Sahyapravashi Final

Sahyapravashi is a web application designed to help users explore and book treks to various forts in Maharashtra. The platform provides detailed information about forts, booking options, and user management features.

## Features
- Explore detailed information about forts
- User registration and login
- Bookings management
- Admin dashboard
- Contact and About pages
- Integrated payment system

## Technologies Used
- Node.js
- Express.js
- HTML, CSS, JavaScript
- Mysql

## Folder Structure
- `public/` - Static files (HTML, CSS, JS)
- `images/` - Fort and site images
- `uploads/` - Uploaded images
- `server.js` - Main server file
- `config.js` - Configuration file

## Getting Started
1. Clone the repository:
   ```sh
   git clone https://github.com/Abhishekpanwar-23/Sahyapravashi.git
   ```
2. Install dependencies:
   ```sh
   npm install
   ```
3. Start the server:
   ```sh
   node server.js
   ```
4. Open your browser and go to `http://localhost:3000`
